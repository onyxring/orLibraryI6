## orLibrary for I6 2.x
The orLibrary is an extension framework, and a collection of extensions, for the Inform 6 compiler and standard library. 

If you are not sure where to start, the [User's Guide](https://github.com/onyxring/orLibraryI6/blob/main/_extras/orLUG.pdf) is probably the best place [(alternative online viewer)](https://nbviewer.org/github/onyxring/orLibraryI6/blob/main/_extras/orLUG.pdf), assuming you are already familiar with Inform 6. 


If you're new to I6, you may need to start at the [DM4](https://www.inform-fiction.org/manual/html/index.html) to learn the fundamentals first.
