## orLibrary for I6 2.x
The orLibrary is an extension framework, and a collection of extensions, for the Inform 6 compiler and standard library. 

If you are not sure where to start, the orLibrary User's Guide (orLUG) is probably the best place, assuming you are already familiar with Inform 6.  


If not, you may need to start at the [DM4](https://www.inform-fiction.org/manual/html/index.html). 
(https://github.com/onyxring/orLibraryI6)
